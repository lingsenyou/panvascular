Concept tracker: Suitcordance live count

Suitcordance describes the match between an interventional device and its vascular environment, combining short-term mechanical suitability with long-term biological concordance. This panel runs a live query for the term so its uptake in the indexed literature can be seen, and audited, directly.

Results

Where the data comes from. Records are queried live from the OpenAlex API, an open index of scholarly works released under CC0, and each entry links to its DOI so the source can be verified. This page stores no corpus of its own, ranks nothing by hand, and produces no machine-written summaries.

On citation counts. Indexes genuinely disagree, so each figure carries the name of the index that produced it. Where a DOI is present the Crossref cited-by tally is fetched as well, which usually runs a little ahead of OpenAlex. Google Scholar counts higher again because it also sweeps preprints, theses and unindexed venues, but it publishes no API and its terms forbid automated collection, so it is never queried here. The Scholar link on each record simply hands the search to Google Scholar so its number can be read at the source.
